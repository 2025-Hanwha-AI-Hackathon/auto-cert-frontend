# 인증서 관리 시스템 - 흐름도

## 📊 시스템 전체 흐름도

```
┌─────────────────────────────────────────────────────────┐
│                    사용자 접속                          │
└────────────────────┬────────────────────────────────────┘
                     │
                     ▼
         ┌───────────────────────┐
         │   App 컴포넌트 마운트  │
         └───────────┬───────────┘
                     │
                     ▼
         ┌───────────────────────┐
         │   초기 데이터 로딩     │
         │  loadCertificates()   │
         └───────────┬───────────┘
                     │
                     ▼
         ┌───────────────────────┐
         │  API 호출             │
         │ GET /api/v1/certificates │
         └───────────┬───────────┘
                     │
                     ▼
         ┌───────────────────────┐
         │   데이터 변환          │
         │ transformCertificate() │
         └───────────┬───────────┘
                     │
                     ▼
         ┌───────────────────────┐
         │   화면 렌더링          │
         │  - 통계 대시보드       │
         │  - 인증서 카드 그리드  │
         │  - 필터/검색          │
         └───────────────────────┘
```

## 🔄 인증서 추가 흐름

```
                    사용자
                      │
                      │ "새 인증서 추가" 버튼 클릭
                      ▼
         ┌─────────────────────────────┐
         │   Add Dialog 열림           │
         │  - 도메인 입력 필드          │
         │  - 챌린지 타입 선택         │
         └────────────┬────────────────┘
                      │
                      │ 사용자 입력
                      ▼
         ┌─────────────────────────────┐
         │   입력 검증                 │
         │  ✓ 도메인 형식 검증          │
         │  ✓ 필수 필드 확인            │
         └────────────┬────────────────┘
                      │
                      │ 검증 성공
                      ▼
         ┌─────────────────────────────┐
         │  API 호출                   │
         │ POST /api/v1/certificates   │
         │  {                           │
         │    domain: "example.com",   │
         │    challengeType: "HTTP"    │
         │  }                           │
         └────────────┬────────────────┘
                      │
                      │ 응답 수신
                      ▼
         ┌─────────────────────────────┐
         │   데이터 변환 및 추가        │
         │  setCertificates([...prev])  │
         └────────────┬────────────────┘
                      │
                      │
                      ▼
         ┌─────────────────────────────┐
         │   Dialog 닫기               │
         │   화면 업데이트              │
         │   성공 메시지 표시           │
         └─────────────────────────────┘
```

## 🔄 AI 채팅 필터링 흐름

```
                    사용자
                      │
                      │ "유효한 인증서 보여줘" 입력
                      ▼
         ┌─────────────────────────────┐
         │   ChatSidebar               │
         │   handleSend() 실행         │
         └────────────┬────────────────┘
                      │
                      ▼
         ┌─────────────────────────────┐
         │   generateMockResponse()    │
         │   명령어 분석                │
         └────────────┬────────────────┘
                      │
                      │ "유효" 키워드 감지
                      ▼
         ┌─────────────────────────────┐
         │   onFilterChange('valid')   │
         │   호출                      │
         └────────────┬────────────────┘
                      │
                      ▼
         ┌─────────────────────────────┐
         │   App 컴포넌트              │
         │   setFilterStatus('valid')  │
         └────────────┬────────────────┘
                      │
                      ▼
         ┌─────────────────────────────┐
         │   filteredCertificates      │
         │   재계산                    │
         │   (status === 'valid')      │
         └────────────┬────────────────┘
                      │
                      ▼
         ┌─────────────────────────────┐
         │   화면 업데이트              │
         │   유효한 인증서만 표시       │
         │   AI 응답 메시지 표시        │
         └─────────────────────────────┘
```

## 🎯 상태 관리 흐름

```
┌─────────────────────────────────────────────────────────┐
│                   App 컴포넌트 상태                      │
├─────────────────────────────────────────────────────────┤
│  certificates: []          // 인증서 목록               │
│  loading: boolean          // 로딩 상태                 │
│  error: string | null      // 에러 메시지               │
│  searchQuery: string       // 검색어                    │
│  filterStatus: string      // 필터 상태                 │
│  addDialogOpen: boolean    // 추가 다이얼로그 열림      │
│  renewDialogOpen: boolean  // 갱신 다이얼로그 열림      │
│  detailDialogOpen: boolean // 상세 다이얼로그 열림      │
└─────────────────────────────────────────────────────────┘

         │
         │ 상태 변경
         ▼
┌─────────────────────────────────────────────────────────┐
│                파생 상태 (Derived State)                │
├─────────────────────────────────────────────────────────┤
│  stats: {                                                │
│    total: number                                        │
│    valid: number                                        │
│    expiringSoon: number                                 │
│    expired: number                                      │
│  }                                                       │
│                                                          │
│  filteredCertificates: []  // 필터링된 인증서 목록      │
└─────────────────────────────────────────────────────────┘
```

## 🔌 API 호출 흐름

```
         컴포넌트
            │
            │ API 함수 호출
            ▼
    ┌───────────────┐
    │  services/api │
    │     .js       │
    └───────┬───────┘
            │
            │ fetch() 호출
            ▼
    ┌───────────────┐
    │  handleResponse() │
    │  - 204 처리      │
    │  - JSON 파싱     │
    │  - 에러 처리     │
    └───────┬───────┘
            │
            │ 응답 데이터
            ▼
    ┌───────────────┐
    │ transformCertificate() │
    │  - 날짜 변환           │
    │  - 형식 변환           │
    └───────┬───────┘
            │
            │ 변환된 데이터
            ▼
         컴포넌트
         상태 업데이트
```

## 🎨 UI 컴포넌트 계층 구조

```
App (메인)
│
├─ Header
│   ├─ 로고 & 제목
│   └─ "새 인증서 추가" 버튼
│
├─ Main Content
│   ├─ CertificateStats
│   │   ├─ 전체 카드
│   │   ├─ 유효 카드
│   │   ├─ 곧 만료 카드
│   │   └─ 만료 카드
│   │
│   ├─ Filter Section
│   │   ├─ 검색 입력창
│   │   └─ 필터 드롭다운
│   │
│   └─ Certificates Grid
│       └─ CertificateCard × N
│           ├─ 아이콘
│           ├─ 정보
│           ├─ 상태 배지
│           ├─ 상세 정보
│           ├─ "상세 보기" 버튼
│           └─ "갱신하기" 버튼
│
├─ Dialogs
│   ├─ Add Dialog
│   ├─ Renew Dialog
│   └─ Detail Dialog
│
└─ ChatSidebar
    ├─ 채팅 버튼 (플로팅)
    └─ 사이드바
        ├─ 헤더
        ├─ 메시지 영역
        └─ 입력 영역
```

## 🎯 AI 채팅 명령 처리 흐름

```
        사용자 입력
            │
            ▼
    ┌───────────────┐
    │  명령어 분석   │
    └───────┬───────┘
            │
    ┌───────┴───────┬───────────┬──────────┐
    │               │           │          │
    ▼               ▼           ▼          ▼
필터링 명령    조회 명령    갱신 명령    통계 명령
    │               │           │          │
    │               │           │          │
    ▼               ▼           ▼          ▼
필터 적용      API 호출     API 호출    통계 표시
    │               │           │          │
    │               │           │          │
    ▼               ▼           ▼          ▼
화면 업데이트   결과 표시   결과 표시   응답 메시지
    │               │           │          │
    └───────────────┴───────────┴──────────┘
                      │
                      ▼
                 AI 응답 표시
```

이 문서는 시스템의 주요 흐름을 ASCII 다이어그램으로 시각화한 것입니다.
